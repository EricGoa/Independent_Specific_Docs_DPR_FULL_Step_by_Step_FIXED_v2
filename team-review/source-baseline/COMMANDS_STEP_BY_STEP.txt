IMPORTANT
=========
Run each command separately. A PASS does not launch the next command.
If a document failed at a later stage yesterday, you may start from that stage
after confirming the earlier evidence/object state is still valid.

INCREMENTAL WORKFLOW
====================
Rerun Step1, DROID, PoC2, PoC3, PoC4 and PoC6 for the job. Completed files
are reused after fixity checks. DROID characterizes newly received files.
Use a new --staging-dir for each changed package, and the same explicit
--ingest-records-dir across PoC8 and PoC9. PoC9 appends v2, v3, etc.,
retaining previous versions and logical files. Identical ingest adds no version.
See WORKFLOW_ANALYSIS.md for record compatibility, tests and limitations.
