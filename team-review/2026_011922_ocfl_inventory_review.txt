3. DEVIATIONS

1. id - The object UUID is given bare. The profile requires the urn:uuid: form
   (urn:uuid:ec1921e0-76fd-4ab3-8b4a-0d1f105fc2ad): the same UUID as the PREMIS intellectual
   entity and the METS @OBJID, which carry it without prefix (DPM23).

2. user/name - No deviation in form: names a person in every version. The name must be that
   of the authorizer of the version's AIP creation event, as registered in the agent registry.
   Since PREMIS has neither that event nor any person agent, it cannot be confirmed that
   Eric Gao authorised the commits.

3. user/address - Absent. Required: a mailto: URI [RFC 6068] with the authorizer's e-mail
   address as registered in the agent registry (e.g. mailto:<name>@wto.org).

4. message - Free text, and the same for v2 and v3. Required: the version's selection basis, a
   space, an em dash, a space, and a short description. On the evidence of the package, the
   three messages would read:
     v1  new_document - initial ingest (es)
     v2  language_added - French added (fr)
     v3  language_added - English added (en)
   with an em dash in place of the hyphen. language_added is the proposed value for a new
   language (profile, vocODRNSSelectionBasis); the selection basis is not recorded anywhere in
   the package, so these are inferred from the files added in each version.

Under DPM3 and DPM14 a failed check commits nothing and holds the bag. That v1, v2 and v3 were

5. CONSEQUENCE

Committed OCFL versions are immutable, so the commit records cannot be corrected in place.
For a test object, the clean route is to re-ingest 2026_011922 as a new object once the ingest
side is fixed; otherwise v1-v3 stand and the records are explained in a later version.
